# SIST™ — System Intelligence & Strategic Tactics

> Public-facing reference repository for SIST™.

## Purpose

This repository contains the public website and intentionally limited public materials for SIST™.

SIST is an **independent AI research and intelligence-analysis platform** built for structured records, adversarial review, source-grounded synthesis, and human decision support.

The public repository is **not** the private implementation repository and does not contain confidential prompts, internal orchestration instructions, proprietary evaluation logic, private datasets, credentials, or restricted integrations.

## Current public operating model

The canonical public pipeline is:

**INTAKE → LIBRARIAN → INGESTOR → RESEARCHER → ANALYST → LAWCLERK → COUNTERMEASURES → BRIEFER → DEPLOY MASTER**

Five public control gates divide that lifecycle: Intake, Ingestion, Intelligence, Adversarial, and Deployment.

The current five divisions are:

- Criminal Defense Division
- Healthcare Intelligence Division
- Consumer Advocacy Division
- Immigration & Humanitarian Advocacy Division
- Institutional Accountability Division

## Validation boundary

SIST is a working architecture. Public materials do **not** claim zero-error operation, universal superiority over single-model AI, or statistical proof across every task and domain. Those claims require controlled validation.

## Operating scope

SIST provides AI-assisted research, record analysis, adversarial review, and decision support. It is not a government agency, law firm, healthcare provider, or licensed representative. Human users remain responsible for professional review and consequential decisions.
