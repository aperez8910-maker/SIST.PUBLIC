# SIST™ — Public Council Overview

The SIST™ AI Council is a public-facing description of a multi-perspective analytical concept within the broader SIST architecture.

## Public concept

Different analytical perspectives may be used to examine information, identify weaknesses, challenge assumptions, and support synthesis.

The public repository intentionally does not disclose the private configuration, exact roles, prompts, model-routing rules, evaluation logic, internal deliberation procedures, or orchestration mechanics used by any production implementation.

## Public relationship to SIST

SIST™ is the broader proprietary architecture. The Council is one conceptual component described publicly to explain the system at a high level.

The public description is **not an implementation specification** and should not be used to infer the private system design.
